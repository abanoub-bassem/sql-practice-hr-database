# SQL Server HR Database Practice

## Overview
A collection of SQL queries written while practicing SQL Server
using an HR sample database.

## Topics Covered
- SELECT, WHERE, and ORDER BY
- Aggregate Functions and GROUP BY
- INNER JOIN
- Subqueries and Common Table Expressions (CTEs)
- CASE Expressions
- Window Functions
- RANK, DENSE_RANK, and ROW_NUMBER
- LAG and LEAD
- Aggregate Window Functions
- Salary Analysis

## Tools
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Purpose
This project demonstrates my SQL practice and my understanding
of querying and analyzing relational data.
